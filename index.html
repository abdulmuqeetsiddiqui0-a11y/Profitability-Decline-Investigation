How it works

Monthly data from four departments is joined into one table and a profit-and-loss view. The analyst compares the cost lines between the last quarter before the decline and the latest quarter, then tests every KPI pair across departments for relationships between month-to-month changes at lags of 0 to 2 months. Strong links are chained, and a search finds loops where the effects feed back on themselves. In production an LLM would write the findings and answers from these computed numbers only. Correlation is not proof of cause, so confirm the main links with a small test before a large change.
